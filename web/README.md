# FacturApp · web

Sitio estático (Next.js + Tailwind v4) con la demo de pedidos online y el contacto por WhatsApp con el bot.

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

`lib/contacto.ts` es el contrato con el bot (token, firma invisible y texto): no se toca sin cambiar el backend.
